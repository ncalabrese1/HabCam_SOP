# Data Use & Scientific Documents

## Data Use

The data is used to develop indices of abundance and size composition of Atlantic sea scallop for the stock assessments. Additional fisheries and ecosystem data collected from the images is also processed for use in future stock and ecosystem assessment needs.

A number of other surveys collect data on scallop distribution, abundance, and size supported by the Center's Scallop Dredge survey and the Research Set Aside Program (including dredge, video drop camera, and an additional HabCam survey). The intent of these multiple surveys is to increase the accuracy and precision of the sea scallop assessment through thorough fisheries-independent surveys.
