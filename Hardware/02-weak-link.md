# Mechanical Weak Link Assembly

The mechanical weak link protects the primary tow cable and ship winch from catastrophic over-tension during seafloor snags[cite: 8]. It is installed between the towing bridle and the mechanical cable clevis[cite: 6, 8].

### Assembly Procedure

1. Align the large holes on the outer housing with the large holes on the padeye inner housing (bridle), positioning set screws facing upwards[cite: 8]. Each side of the bridle and outer shell features one large hole and one small hole[cite: 8].
2. Slightly lift the bridle to slip the outer shell over the inner housing[cite: 8].
3. Rotate components until all matching holes align perfectly[cite: 8].
4. Insert the shear pin, wiggling the bridle and outer shell until the pin slides fully into position[cite: 8].
5. Ensure the shear pin is centered inside the body and sits completely flush on both sides[cite: 8].
6. Using a 3mm hex bit, tighten the set screws to **7.8 Nm** to lock the pin flush[cite: 8]. (Note: Set torque on torque wrench prior to tightening)[cite: 8].
7. Attach the mechanical clevis to the weak link using the primary termination bolts[cite: 8]. Ensure the set screws remain secured and protected by a hose clamp[cite: 8].
