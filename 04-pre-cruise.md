# Pre-Cruise Operational Checklist & Procedures

## 1. Pre-Cruise Checklist

### 6 Months Out (~November)
* [ ] Confirm ship time and set cruise date[cite: 7]
* [ ] Send Seabird 37, Seabird 49 CTDs and Wetlabs ECO-Triplet puck for RMA calibrations[cite: 7]
* [ ] Begin long-lead supply ordering[cite: 7]
* [ ] Ship damaged gear for repair[cite: 7]

### 15 Weeks Out
* [ ] Audit IT machine software security patches[cite: 7]

### 12 Weeks Out
* [ ] Configure 2026 server directories and GUIs[cite: 7]
* [ ] Retrieve POPDY flash drive & install R packages on annotation machines[cite: 7]
* [ ] Verify static IP addresses on annotation stations[cite: 7]
* [ ] Install Coastal Explorer & sonar software on field laptops[cite: 7]

### 8 Weeks Out
* [ ] Prepare vehicle for WHOI Sundance Tank calibration test[cite: 7]
* [ ] Pack tank test toolkits[cite: 7]
* [ ] Issue science center staffing call[cite: 7]

### 6 Weeks Out
* [ ] Execute WHOI Seawater Tank calibration test[cite: 7]
* [ ] Replace pinger batteries (Benthos UAT 376)[cite: 7]

### 5 Weeks Out
* [ ] Send "You are scheduled" email packet (expectations, medical clearance, dietary forms, packing list)[cite: 7]
* [ ] Construct watch bills & assign stateroom berthing[cite: 7]

### 1 Week Out
* [ ] Issue logistics email (departure times, meeting points, parking permits, weather limits)[cite: 7]
